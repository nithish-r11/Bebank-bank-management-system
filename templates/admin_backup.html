Safe Disaster Recovery & Restore Console

To prevent race conditions, data loss, or server corruption, web-based arbitrary database overwriting is strictly prohibited. Database recovery is performed through the safe, authenticated CLI utility.

Standard Recovery Procedure:
  1. Stop the Application Server: Terminate any active web processes (e.g. Ctrl+C in the running Django development terminal).
  2. Execute the Restore Utility: Run the safe management command specifying the snapshot path: 
    python manage.py restore_sqlite_backup "backups/bebank_backup_example.sqlite3" --confirm
  3. Automated Safety Safeguards: The command automatically checks SQLite integrity (PRAGMA integrity_check) of the source file, creates a pre-restore safety snapshot of the existing database, performs transactional restore, and validates the restored target.
  4. Restart the Application: Launch python manage.py runserver once the restore command reports success.
Compliance Note: All backup downloads and CLI recovery actions are immutably logged into EmployeeActivityLog. Never attempt restoring backups from untrusted external sources.
